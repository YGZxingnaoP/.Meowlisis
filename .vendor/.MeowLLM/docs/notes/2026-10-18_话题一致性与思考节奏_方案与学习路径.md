## 1. 需求重新翻译（这次对准）

| 你要的 | 本质 | 和 δ-mem 的关系 |
|---|---|---|
| 聊动漫就停在动漫，别漂到吃饭 | **话题条件化**：当前话题持续偏置注意力 | δ-mem 的形态天生适合，但当前用法（存事实）不对 |
| 顽梗、联想、地狱笑话、言外之意都能读懂 | **语用理解**（pragmatics）：多意图假设 + 反讽/夸张/禁忌位移 | 单靠注意力偏置不够，但偏置能降低"退化成字面理解"的概率 |
| 思考有节奏、别机械助手腔 | **解码调度 + 风格控制** | 属于引擎调度层，不是记忆层 |
| （新）激素调控、注意力仿生 | **全局标量/向量调控**（增益、遗忘率、探索度） | 这正是 δ-mem 骨架能扩展的方向 |

**一句话**：δ-mem 的真正价值不是"记住 Margot"，而是它已经跑通了
**"外挂一小撮参数 → 按 owner 隔离 → 运行时热加载 → 参与 attention 计算 → 可持久化"** 这条骨架。
把"记忆"换成"话题偏置 / 激素 / 语用模式"，这套基础设施可以原样复用。

## 2. 实测给出的不是"失败"，是四条设计约束

v2 的剂量曲线（同场景、同 50 轮，只改 α）：

| α_scale | α | 事实召回 |
|---|---|---|
| ×1（训练默认） | ≈16 | 0/4 |
| **×4** | **≈64** | **4/4**（两次复现） |
| ×16 | ≈256 | 0/4，输出崩坏 `ffff…` / `respect respect…` |

由此得到四条硬约束，任何"挂载式微调"都必须满足：

1. **必须自校准，不能写死系数。** 训练出来的强度落在可用窗口外面是常态，
   而且窗口很窄（16→0，64→满，256→崩）。
2. **不能压过上下文。** α×4 时 plant 还在上下文里，`with_mem` 反而答错 ——
   参数干预不是加法，过界会把 coherence 一起打坏。
3. **必须有遗忘/衰减语义。** 实测偏好约 25 轮后从 `spicy` 磨成 `healthy`，
   句式不变只换形容词 —— 这是"退回模板"，不是"忘了"。
4. **必须能度量退化。** 崩坏有非常具体的形态（`ffff` 死循环、`respect respect` 重复、
   `It's fun, healthy, and customizable!` 这类套话），可以写成自动回归测试。

## 3. δ-mem v2：把"记忆头"改成"调控头"

### 3.1 现在挂的是什么

```
每层：w_q/w_k/w_v/w_beta（产生记忆向量）+ w_dq/w_do（Δq/Δo 投影）+ log_alpha（强度）
作用：Δq、Δo 注入 attention 的 q/o 两侧
状态：每层一个 r×r 矩阵（r=64 ⇒ 64×64），delta 规则覆盖式更新
```

### 3.2 可以加/换的挂载点（不改 backbone）

| 挂载点 | 做什么 | 对应你的目标 |
|---|---|---|
| **bias-only 适配**（只调 bias / 只调 scale） | 极低成本的方向控制，已有工作证明够用（见 §5 [1]） | 话题偏置 |
| **注意力 bias**（在 QK^T 上加低秩偏置） | 直接改"看哪里" | 话题一致性最直接的一条 |
| **输出侧 scale**（对数分布做温度/平坦度调整） | 控制"敢不敢顽梗" | 语气、幽默 |
| **全局标量组**（gain / beta / 探索度 / 重复惩罚） | 模拟"激素水平" | 激素调控 |
| **分层强度**（不同层不同倍数） | 浅层管风格、深层管内容 | 减少互相干扰 |

### 3.3 正交分解（关键工程点）

不要把"话题 / 激素 / 人格"塞进同一份状态，否则它们会互相打架（v2 的干扰就是征兆）。
建议三组独立挂载，各自有独立强度与独立衰减：

```
topic_i   ：按会话/话题，replace 写入，短半衰期
hormone   ：全局标量组，按"情绪/场景"设置，中等半衰期
persona   ：长期，几乎不衰减（对应现在的 abmem 那层）
```

### 3.4 触发方式（比"每轮 append"重要）

v2 里唯一成功的一次是：**只写一句 plant，50 轮后还完整召回**。
而主项目现在每轮 `remember()` 追加对话流水 —— delta 是覆盖式写入，
**每轮都写 = 只记得最近几轮**。所以：

- 话题卡：**每 N 轮 or 话题切换时 replace**，不是每轮 append
- 激素：按事件触发（用户开玩笑 / 情绪波动 / 深夜）
- 事实：继续走应用层的 tags+维度（已验证最优），不要塞进 δ-mem

## 4. 关于"顽梗 / 地狱笑话 / 言外之意"：光靠偏置不够

这类输入要求的是**语用理解**，不是"知道得更多"。当前模型的失败模式是
**默认做字面理解**（把反讽当陈述、把夸张当事实）。可用的三段式：

```
① 先假设后回答：让模型先列出"这句话可能的几种意思"（含玩笑/反讽/试探），
   再选一个回应 —— 这一步可以靠 prompt 强制，不需要训练
② 用偏置压掉"字面理解"这个高概率分支（δ-mem 挂载点 / bias-only 适配）
③ 用数据补模式：语用标注样本（幽默/反讽/暗黑幽默）适合做小 LoRA 或偏置微调
```

现成可用的语料/评测在 §5 [7][8][9][10]。**注意**：这些评测的结论普遍是
"LLM 在暗黑幽默与言外之意上显著落后于人类，few-shot 帮助有限" ——
这既说明难度，也说明"值得做"。

## 6. 建议的实验骨架（先建度量，再调参）

| 指标 | 怎么算 | 目标 |
|---|---|---|
| 话题保持率 | 第 N 轮回复 vs 话题卡的语义相似度（用小模型或 embedding） | ≥0.7 保持 20 轮 |
| 漂移率 | 话题外名词占比（先建话题词表） | ≤5% |
| 模板腔比例 | 命中套话表（`It's fun, healthy, and customizable!` / `could be a healthy, tasty meal!`） | ≤10% |
| 语用命中 | 暗黑幽默/反讽集上的"是否识别出非字面义" | 基线 + 明确提升 |
| 节奏 | 每轮段数 / 段均长 / 停顿位置 | 段数≥2、段长 8~25 字 |
| 退化告警 | 重复 n-gram、`\ufffd`、单字符循环 | 必须为 0 |

**先跑基线再动参数**，并且每改一版都回归这张表 —— v2 的教训就是"没度量就会把
`α×4` 的干扰当成噪声"。

## 7. 一句话总结

> 把 δ-mem 从"记忆头"改造成**"调控头"**：
> 挂载点从 q/o 扩到 attention-bias / 输出 scale / 全局标量；
> 状态按 **topic / hormone / persona** 三组正交拆分，各自独立强度与衰减；
> 强度**必须自校准**（训练值落在窗口外是常态），并且必须有退化回归测试。
> 事实记忆继续留在应用层（tags+维度），不要搬进 δ-mem。
