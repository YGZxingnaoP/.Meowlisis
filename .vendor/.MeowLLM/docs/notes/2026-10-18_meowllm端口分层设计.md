# MeowLLM 端口分层设计（重写版 v2）

> 日期：2026-10-18
> **v1 作废**。v1 把 meowllm 当成"需要共享基础设施的特殊平台"，这是错的：
> deepseek / aliyun / gemini 在 `func/` 下**没有任何目录**，每个模块的 `port/deepseek.py`
> 都是自包含的。meowllm 必须**完全并列**，不能有 `func/meowllm/`。

---

## 1. 原则（这次按你说的定）

1. **meowllm = 一个平台**，与 deepseek / aliyun / gemini 同级并列。
2. `func/` 下**不允许**出现平台级目录（现在没有 `func/deepseek/`，将来也不会有 `func/meowllm/`）。
3. 每个 `func/<模块>/port/meowllm.py` **结构与同目录的 deepseek.py 一致**：自己读配置、自己建
   `OpenAI(...)`、自己拼参数、暴露 `chat` / `chat_stream`。
4. 平台之间**互不引用**；模块的 port 只被本模块使用。
5. `.vendor/.MeowLLM/` **允许改** —— 服务端规则（含 δ-mem）就放那里。

---

## 2. 现状对照：为什么现在的 meowllm 端口不合格

| | `port/deepseek.py`（81 行） | `port/meowllm.py`（60 行） |
|---|---|---|
| 读配置 | 自己从 `LLMConfig.deepseek_*` 读 8 个字段 | 全部委托 `func.meowllm.MeowLLMClient` |
| 建客户端 | `OpenAI(api_key=..., base_url=...)` | 在别的目录里建 |
| 拼参数 | 自己的 `_build_params` | 在别的目录里拼 |
| 依赖 | `openai` + `func.llm.config` + `func.log` | **`func/meowllm/`（平台级共享目录）** ← 违规 |

结论：`func/meowllm/` 必须消失，其内容按性质拆到三处：

| 现在住在 `func/meowllm/` 的东西 | 性质 | 新归属 |
|---|---|---|
| `client.py`（建客户端、拼 extra_body、thinking、tap） | 平台协议细节 | **摊回 12 个 port**（每个 ~95 行，与 deepseek 同构） |
| `config.py`（读 vendor config.yml、port.json） | 端点发现 | 端点进**根 config.yml 的 `llm.meowllm`**；`port.json` 归服务端，由启动器同步 |
| `memory.py`（uid→owner、线程上下文） | 项目策略，与平台无关 | `func/catbrain/UserMemory/identity/dmem_owner.py` |
| —— | 工具回合不挂记忆 | **挪进服务端**（见 §4） |

## 3. 目标结构

```
func/llm/port/meowllm.py                     ← 自包含，~95 行（和 deepseek.py 同构）
func/toolbox/port/meowllm.py                   同上，只是读 TBoxConfig 的参数
func/toolbox/meowvision/port/meowllm.py        同上
... 共 12 个，各自独立

func/llm/config.py                           ← 加 meowllm 平台段（8 行，和 deepseek 段并列）
func/toolbox/config.py                         ← 同上（各模块读根 llm.meowllm）
... 共 12 个 config.py，各加 8 行

func/catbrain/UserMemory/identity/dmem_owner.py   ← ★新增：uid→owner 策略（唯一非平台概念）

.vendor/.MeowLLM/                            ← 协议 + dmem + 「工具回合忽略 owner」规则

删除：func/meowllm/（整个目录，4 个文件）
```

**调用点零改动**：12 个 port 的类名与别名保持不变。

## 4. 关键决策：把「工具回合不挂记忆」放进服务端

今天的补丁写在客户端（`func/meowllm/client.py`），要跟着 12 个端口走。挪到服务端后，
**端口里一行 dmem 代码都不需要**，而且任何客户端（curl / 脚本 / 未来新平台）都自动守规矩。

`meowllm/engine/dualstream/engine.py::_apply_memory()` 最前面加：

```python
if params.memory_owner and params.tools:
    self.dmem_registry.use(None)
    return {"attached": False, "reason": "tools"}
```

依据（实测，同一段 200 条消息 + 工具定义 + 同一条指令）：

| | finish_reason | 输出 |
|---|---|---|
| 无记忆 | `tool_calls` | 结构化调用 ✓ |
| 带记忆 α×1 | `stop` | 正文里出现 `qq_send_message{"contact": "..."}` |
| 带记忆 α×4 | `stop` | 重复死循环 |

δ-mem 注入会扰动开头的 `<tool_call>` 标记 → `parse_tool_calls` 认不出 → 整段当正文 → 工具不执行。
**这是服务端的规则，不是某个客户端的责任。**

> 写入不受影响：`DmemBridge.remember()` 是独立的 `POST /control/dmem/write`，
> 工具回合照样写记忆，只是这一轮不读。

## 5. 端点归属：`port.json` 归服务端，端口只读 config

deepseek 的 `base_url` 来自 config —— meowllm 也一样，只是这个值**由启动器回写**：

```yaml
llm:
  meowllm:
    base_url: http://127.0.0.1:18100/meowllm/v1   # 启动器按服务端实际端口同步
    model: meowllm-local
    temperature: 0.8
    max_tokens: 256
    top_p: 0.9
    top_k: 40
    repeat_penalty: 1.05
    thinking_level: off
```

- `port.json` 仍由服务端写（它自己的状态），**项目侧不再读它**
- 启动器（`start.bat` / `cloud_serve.py` / `run_lab.bat`）在服务就绪后把实际 URL 写进 `llm.meowllm.base_url`
- 各模块 config 类统一从**根 `llm.meowllm`** 取（它们本来就读同一个 config.yml），共 8 行模板：

```python
meow = cfg.get('meowllm') or (cfg.get('llm') or {}).get('meowllm') or {}
self.meowllm_base_url       = meow.get('base_url', 'http://127.0.0.1:18100/meowllm/v1')
self.meowllm_model          = meow.get('model', 'meowllm-local')
self.meowllm_temperature    = meow.get('temperature', 0.8)
self.meowllm_max_tokens     = meow.get('max_tokens', 256)
self.meowllm_top_p          = meow.get('top_p', 0.9)
self.meowllm_top_k          = meow.get('top_k', 40)
self.meowllm_repeat_penalty = meow.get('repeat_penalty', 1.05)
self.meowllm_thinking_level = meow.get('thinking_level', 'off')
```

## 6. 端口目标代码（`func/llm/port/meowllm.py`，~95 行）

```python
# -*- coding: utf-8 -*-
# func/llm/port/meowllm.py
# MeowLLM 本地模型（OpenAI 兼容接口，支持 function calling / δ-mem）

from typing import List, Dict, Optional
from openai import OpenAI

from func.log.default_log import DefaultLog
from func.llm.config import LLMConfig


class MeowLLMLLM:
    """MeowLLM 流式客户端（OpenAI 兼容接口）。

    与 deepseek.py 完全同构。本平台多三个请求字段：
        * top_k / repeat_penalty 必须在**请求顶层**（放进 meowllm 块会被 schema 静默丢弃）
        * meowllm.thinking_level 三档：off / low / medium / high
        * meowllm.memory_owner δ-mem 归哪个用户（工具回合由服务端忽略）
    """

    _LEVELS = ("off", "low", "medium", "high")

    def __init__(self, config: Optional[LLMConfig] = None):
        self.log = DefaultLog().getLogger()
        self.config = config if config is not None else LLMConfig()
        self.base_url = self.config.meowllm_base_url
        self.model = self.config.meowllm_model
        self.temperature = self.config.meowllm_temperature
        self.max_tokens = self.config.meowllm_max_tokens
        self.top_p = self.config.meowllm_top_p
        self.top_k = self.config.meowllm_top_k
        self.repeat_penalty = self.config.meowllm_repeat_penalty
        self.thinking_level = self.config.meowllm_thinking_level

        try:
            # 本地服务不鉴权，api_key 只是 OpenAI SDK 的必填占位
            self.client = OpenAI(api_key="meowllm-local", base_url=self.base_url)
            self.log.info(f"MeowLLM 客户端初始化成功，端点: {self.base_url}，模型: {self.model}")
        except Exception as e:
            self.log.error(f"初始化 MeowLLM 客户端失败: {e}")
            self.client = None

    @classmethod
    def _resolve_level(cls, enable_thinking=None, thinking_level=None) -> str:
        if thinking_level in cls._LEVELS:
            return thinking_level
        if enable_thinking is False:
            return "off"
        if enable_thinking is True:
            return "medium"
        return ""                      # 交给配置默认值

    def _build_params(self, messages: List[Dict], tools: Optional[List[Dict]] = None,
                      options: Optional[Dict] = None, tool_choice=None,
                      enable_thinking: Optional[bool] = None,
                      thinking_level: Optional[str] = None,
                      stream: bool = True) -> Dict:
        options = options or {}
        params = {
            "model": options.get("model", self.model),
            "messages": messages,
            "stream": bool(stream),
            "temperature": options.get("temperature", self.temperature),
            "top_p": options.get("top_p", self.top_p),
            "max_tokens": options.get("max_tokens", self.max_tokens),
        }
        if tools:
            params["tools"] = tools
        if tool_choice:
            params["tool_choice"] = tool_choice

        block: Dict = {}
        level = self._resolve_level(enable_thinking, thinking_level) or self.thinking_level
        if level:
            block["thinking_level"] = level
        owner = options.get("memory_owner")
        if owner:
            block["memory_owner"] = owner

        params["extra_body"] = {
            "top_k": int(options.get("top_k", self.top_k)),
            "repeat_penalty": float(options.get("repeat_penalty", self.repeat_penalty)),
            "meowllm": block,
        }
        return params

    def chat(self, messages: List[Dict], tools: Optional[List[Dict]] = None,
             options: Optional[Dict] = None, tool_choice=None,
             enable_thinking: Optional[bool] = None,
             thinking_level: Optional[str] = None, **kwargs):
        if not self.client:
            self.log.error("MeowLLM 客户端不可用")
            return None
        params = self._build_params(messages, tools, options, tool_choice,
                                    enable_thinking, thinking_level, stream=False)
        try:
            return self.client.chat.completions.create(**params)
        except Exception as e:
            self.log.error(f"MeowLLM 调用异常: {e}")
            return None

    def chat_stream(self, messages: List[Dict], tools: Optional[List[Dict]] = None,
                    options: Optional[Dict] = None, tool_choice=None,
                    enable_thinking: Optional[bool] = None,
                    thinking_level: Optional[str] = None, **kwargs):
        if not self.client:
            self.log.error("MeowLLM 客户端不可用")
            return iter([])
        params = self._build_params(messages, tools, options, tool_choice,
                                    enable_thinking, thinking_level, stream=True)
        try:
            return self.client.chat.completions.create(**params)
        except Exception as e:
            self.log.error(f"MeowLLM 流式调用异常: {e}")
            return iter([])
```

其余 11 个端口的差别只有三处：**config 类不同、label 不同、个别模块多一个别名**。

## 7. `dmem_owner.py`（唯一非平台的概念）

从 `func/meowllm/memory.py` 搬过去，放 `func/catbrain/UserMemory/identity/` —— 它讲的是
"这个 uid 算不算正式用户、能不能用记忆"，属于用户身份策略，与平台无关。

```python
FIELD = "memory_owner"

def is_formal(uid) -> bool: ...          # "000001" 算正式；"temp-000029" 不算
def owner_for(uid) -> str | None: ...    # 不合格返回 None
def set_current_uid(uid) / clear_current_uid()   # 线程兜底，后台任务不继承
```

调用方（`llm_core`）显式算好 owner 再塞进 `options`：

```python
owner = dmem_owner.owner_for(uid)
stream = self.llm.chat_stream(messages, tools=tools,
                              options={"memory_owner": owner}, ...)
```

线程上下文保留但**降级为兜底**（37 个调用点不必一次改完）。

## 8. 迁移（4 步，每步可独立停）

| 步 | 动作 | 校验 |
|---|---|---|
| **1** | vendor 加 §4 服务端规则 | 带 tools + owner 的请求返回 `attached=False, reason='tools'`；不带 tools 仍 `attached=True` |
| **2** | 12 个 config 类加 meowllm 段；根 config.yml 加 `llm.meowllm` | `LLMConfig().meowllm_base_url` 正确 |
| **3** | 12 个 port 重写为自包含（§6 模板） | 每个 port 能独立 import；12 条 `MeowLLM 客户端初始化成功` |
| **4** | `memory.py` → `dmem_owner.py`；删 `func/meowllm/`；改 3 处调用 | `grep -r "func.meowllm"` 为空；全量 import 回归 |

第 1 步先做最划算：它让当前的客户端补丁变成多余的，之后第 3、4 步可以慢慢来，
期间系统一直是好的。

## 9. 代价（诚实说）

- 12 份 ~95 行重复（≈1100 行）—— 和 deepseek 现状（12 × 81 行）一样；这是这套架构本来的代价，
  换来的是模块可独立演进、没有跨模块耦合。
- 协议演进（如新增 `meowllm.xxx` 字段）要改 12 处 → 缓解：新字段只在服务端加默认值，
  客户端不改也能用；破坏性变更才需要批量改。
- 端点动态性靠"启动器回写 config"解决，多一个隐性约定 → 在 README 写明。

## 10. 不做的事

- 不建 `func/meowllm/`（删掉）
- 不在 vendor 里放项目策略（uid 合法性留在 `dmem_owner.py`）
- 不改 12 个 port 的类名 / 别名 → 调用点零改动
- 不把 12 个 port 合并成一个大客户端
