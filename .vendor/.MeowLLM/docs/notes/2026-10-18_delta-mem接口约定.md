# δ-mem：按用户记忆的接口约定（精简版）

> 一句话：**参数只有一份（全用户共享），状态一人一份（`r×r` 矩阵）**。
> 调用方只需要告诉引擎「这次对话是哪个用户」，别的都不用管。

---

## 1. 传用户的唯一方式

请求体（OpenAI 兼容，`extra_body` 平铺到顶层）：

```json
{
  "messages": [...],
  "meowllm": { "memory_owner": "000001" }
}
```

- `memory_owner` 就是 `character/userinfo/<uid>/` 的那个 **uid**（如 `000001`）
- **只认 `^\d{6}$`**；`temp-*`、空、未知 → 引擎当作"无记忆"，与未挂载完全等价
- 不传 = 无记忆（向后兼容，可随时降级）

Python 客户端：

```python
client.chat.completions.create(
    model="meowllm-local", messages=messages,
    extra_body={"meowllm": {"memory_owner": uid}},
)
```

## 2. 框架侧怎么接（已实现）

| 位置 | 作用 |
|---|---|
| `func/llm/memory_options.py` | **协议唯一出处**：字段名 `FIELD`、uid 合法性、解析顺序 |
| `func/llm/port/meowllm.py` | `supports_memory = True`；`_extra_body()` 里把 uid 塞进 `meowllm.memory_owner` |
| `func/llm/llm_core.py` | 主对话调用处 `options=memory_options.as_options(uid)` |

解析顺序：`显式 uid` → `options["memory_owner"]` → `MeowLLMLtMemBridge().last_uid` → `None`

所以：

- **调用处传 uid** → 最准（推荐）
- **不传** → port 用"最近用户"兜底，照样能用（不必改所有调用点）
- **其它平台**（deepseek/aliyun/gemini）：其 port 只读 `options["model"]`，拿到这个键也不会用；`as_options()` 对非本地模型返回 `None`

## 3. 记忆是谁写进去的

**生成只负责"读"，写入是独立的一步。** 写记忆走控制面：

```http
POST /meowllm/control/dmem/write
{"owner": "000001", "text": "记忆文本…", "mode": "replace"}

→ {"ok": true, "tokens": 842, "chunks": 53, "seconds": 0.4,
   "dir": "/…/character/userinfo/000001/mem"}
```

| mode | 含义 |
|---|---|
| `replace` | 从零重写该用户的记忆（推荐，定期整体刷新） |
| `append` | 在已有状态上继续写（增量累积） |

其它控制面：`GET /control/dmem/status`、`POST /control/dmem/forget`、`POST /control/dmem/use`。

## 4. 存储布局（每用户独立目录，零交叉）

```
character/userinfo/<uid>/mem/
├── delta_mem.pt          状态本体（bf16，r=64/28 层 ≈ 224KB）
├── delta_mem.meta.json   cfg 指纹 + 权重 sha1 + 写入日志 + last_decay_at
├── backup/<时间>/        每次写入自动留一份，保最近 5 份
└── sources/<时间>.md     喂进去的原文快照（保最近 3 份，可追溯）
```

**指纹校验**：`weights_sha1` 或 `cfg_fingerprint` 不匹配 → **拒绝加载**（换权重后不会静默用错记忆）。

---

## 5. 开启条件（`config.yml`）

```yaml
memory:
  delta_mem:
    enabled: true
    weights: labs/dmem_train/out/dmem.safetensors
    layout: userinfo
    userinfo_dir: ../../character/userinfo
    formal_pattern: "^\\d{6}$"
```

未训练/未开启时 `enabled: false`，引擎完全不碰记忆，行为与现在一致。

## 6. 最小自检

```bash
# 1) 引擎侧是否挂上
curl http://127.0.0.1:18100/meowllm/control/dmem/status

# 2) 写一个人的记忆
curl -X POST http://127.0.0.1:18100/meowllm/control/dmem/write \
  -H "Content-Type: application/json" \
  -d '{"owner":"000001","text":"主人叫YGZ醒脑片…","mode":"replace"}'

# 3) 目录是否落在该用户下
ls character/userinfo/000001/mem/
```
