# δ-mem 训练数据来源（真人优先，AI 只做增量）

> 结论先说：**真人公开数据打底（60~70%）→ AI 合成做领域增量（20~30%）→ 项目内数据只当调味（10%）**。
> 项目内数据噪声大（闲聊、情绪、工具调用、弹幕混在一起），不适合当主力。

---

## 1. 为什么"真人数据"不能直接喂

δ-mem 的样本必须是 `(context, query, response)`，且 **response 只有在读过 context 时才写得出来**。
真人公开对话数据**没有这个标注**，它们的形状是"一段连续多轮聊天"。

所以流程是"从真人数据里**构造**监督"，不是"拿过来直接用"：

```
原始：一段多会话真人聊天（session 1..k）
   │
   ├─ 切成会话：前 k-1 段 → 写进状态（context）
   │              第 k 段 user 的话 → query
   │              第 k 段 assistant 的话 → response
   │
   ├─ 过滤（关键，决定成败）：
   │     ① response 必须引用前文事实 —— 判据 = 命名实体/数字/专名 与更早会话有重叠
   │     ② LLM judge 打标："这个回答是否需要前文信息？" 只留"需要"的
   │     ③ 丢掉"嗯/哈哈/好呀"这类不承载信息的轮次
   │
   └─ 产出：(context, query, response) + 负样本（query 与前文无关的轮次，天然存在）
```

**没有第 ② 步，这批数据就是废的** —— 模型会学会"不读记忆也能答"，把 αΔq 压到 0。

你也用同一批才能和论文的 1.31× / 1.20× 对照。**训练用它们会污染评测**。

## 3. 具体配比与规模（目标 1.2 万条）

| 来源 | 条数 | 做法 |
|---|---|---|
| MSC（英→中） | 5000 | 会话切分 + 三重过滤；翻译保留人名/时间/数字 |
| LoCoMo（英→中） | 2000 | 同上；QA 是现成的，只需把 context 转成"记忆流水" |
| PerLTQA（中） | 1500 | 现成中文个人记忆 QA，直接可用 |
| LCCC / NaturalConv（中） | 2000 | 拼"过去 3 天聊天记录 → 今天问昨天的事"；用过滤筛出真有指代的 |
| AI 合成（基于 abstract_memory） | 1000 | 领域增量：主人的偏好/称呼/项目/宠物，这些公开数据里没有 |
| 负样本（记忆里没有） | 500 | 从真人数据里挑"与前文无关"的轮次，答案应是"没聊过" |

## 4. 落地步骤（脚本已经有一半）

```bash
# 1) 下载（HF 走镜像；MSC/LoCoMo 用 git clone + 解压）
export HF_ENDPOINT=https://hf-mirror.com
python -c "from huggingface_hub import snapshot_download as s; s('thu-coai/lccc', local_dir='data/raw/lccc')"

# 2) 构造三元组（要新写，约 150 行）
python labs/dmem_train/build_from_real.py \
    --msc data/raw/msc --locomo data/raw/locomo --perltqa data/raw/perltqa \
    --out data/real.jsonl --filter-judge

# 3) 和 AI 合成混合
python labs/dmem_train/build_data.py --mode llm --limit 1000 --out data/synth.jsonl
python labs/dmem_train/mix.py --real data/real.jsonl --synth data/synth.jsonl --out data/sft.jsonl
```

**`build_from_real.py` 的核心就三件事**：会话切分、实体重叠筛选、LLM judge 打标。
`--filter-judge` 复用的是 `build_data.py` 里已有的 deepseek 端点。

## 5. 质检的三重门（每条样本都要过）

1. **实体门**：response 里至少有 1 个命名实体/数字出现在 `context` 里，且不在 `query` 里
   （否则答案可能从 query 自身推出）
2. **判官门**：LLM 打标"把 context 删掉还能答出来吗"，答"能"的直接丢
3. **NLL 门**：训完之后对每条样本算 `no-context NLL − with-state NLL`，
   **差值 ≤ 0 的样本从训练集里剔除再训一轮**（这叫 self-filtering，很有效）

第 3 门要用训过的模型算，所以顺序是"粗训 → 过筛 → 精训"两阶段。

## 6. 版权与合规（别踩）

## 7. 一句话

先抓 **MSC + LoCoMo + PerLTQA** 这三个（一个管"多会话结构"、一个管"和论文对齐"、
一个管"中文个人记忆"），翻译 + 会话切分 + 三重过滤得到 8500 条真人样本，
再用你项目里的 `abstract_memory` 合成 1000 条补领域，最后按第 5 节过筛。
**项目内数据的作用是"补主人这个人的细节"，不是"当训练主力"。**
