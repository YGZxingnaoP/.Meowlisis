# CatPaws项目的实现方案
## 端口实现
### 实机操作
1. 基于WedDriverAgent的修改，要求能在手机上实现点击，长按，上下左右滑动，放大缩小等所有操作；
1.1. 原项目已经有实现，我需要写成自己的通用接口（名称）进行本地化，方便日后对安卓的支持
2. 屏幕图像传输保留原有逻辑，新增图片直传；
2.1. ocr模式，ocr不再掉本地工具，我需要实现ocr找到文本，以及文本在屏幕上对应的位置，告诉模型完整信息，模型决策交互；
2.2. 图片直传模式，图片直接给多模态模型用于分析如何执行操纵交互；
3. 操作分为单次操作，连续操作，action操作三类；
3.1. 操作以ai调用functioncalling为主。ai调用工具，填写信息，然后提交执行操作；
3.2. 单次操作：适用于大部分场景，如寻找软件，需要滑动屏幕，点击软件图标；如点击返回到上一界面；
3.3. 连续操作：适用于游戏，打字输入的场景，调用该工具，如打字，需要把内容准确转换成拼音，然后输入字母，点击内容；或者能明确知道连续操作，如进入，点击，返回这种连续操作确保可以一下操作完
3.3.1. 补充：打字场景允许回退，请求帮忙打字，打字场景大部分时间其实不必要，仅做举例
3.3.2. 每个交互之间允许延迟，如果不填写延迟，默认是90ms（最小值，不能比这个小）
3.4. action操作：由某些条件触发的操作，这个操作最为复杂，适用于ai觉得图形界面的内容，可作为脚本存放进action文件夹，模型有权直接在action里写入文件，实施action操作直接调用action里的脚本，脚本文件夹下需要包含json，交代脚本的执行逻辑和适用场景
3.4.1. 其中的jumpjump（跳一跳游玩脚本）就是示例，action操作逻辑类似于此，（给每个action一个文件夹和合适的标题，一个脚本可以有多个py文件）
3.4.2. 这里描述的仅仅是操作逻辑，action操作的创建逻辑见“action预设存储”
4. 需要有保护措施，防止ai乱操作
### action预设存储
1. action的主要功能已经在“3.4. action操作”描述，这里主要是创建逻辑
2. action下是所有预设脚本，每个脚本一个文件夹，文件夹用简单的功能概述标题命名
2.1. 每个文件夹下需要有json说明操作的具体详细逻辑，以及适用场景；以及py文件用于执行操作
3. action下当然允许用户自己写脚本，如已经有的jumpjump
4. ai允许自己创建脚本，即ai在完成一段操作之后，可以思考这个操作是否具有泛用性，如点外卖的付款，点击位置通常固定，那么这些操作就可以打包为一个action；或者打开某个软件，操作固定，就可以打包action
5. 所以catpaws下自己也需要配置api，以及写py的工具和审查语言compile的工具，内置一个轻量agent
### 前端预览
1. 目前已经有前端预览，保留现有逻辑的基础上做一些添加
2. 增加操作日志，不是日志！是操作过程，即前端改成手机屏幕在左边，操作内容记录在右边
3. 手机事实画面显示不再为截图，参考`.cam`模块改成视频直传
## 手机端实现（iOS）
1. 手机端基于WDA修改，做一个app，app改名为CatPaw
2. 魔改WDA适用我自己的端口命名，在手机端进行翻译，不再服务端！
3. 需要一个前端界面，用于展示当前连接状态，操作记录，以及一些必要配置项
4. 同时做一些拓展，增加一个适配`.cam`的界面，之后.cam的手机连接可直接用app，不再是浏览器
5. 操作界面需要设计，我的设想是界面以.cam的前端为主，点击操作配置能打开一个界面，返回之后还是.cam界面
5.1. 操作界面能主动退出CatPaw（后台不退），退出后，视频传递（给.cam的如果打开，手机屏幕画面保持正常）自动关闭，但是声音还能播放
6. 需要有停止操作的按钮，防止灾难，我正常操作不会打断
## 主项目对接
1. 新建func\catpaws模块，用于连接主项目和catpaws服务
2. func\catpaws下的内容需要与主模块对接，类似唱歌模块
3. 这是一个流程，如用户说“喵呜操作一下手机，帮我点外卖”然后进入catpaws链路，不再走llm_fast_response，直到目标完成，或者用户主动停止
4. 需要停止词，保护措施，防止ai乱操作，以及方便退出链路
5. 仅仅新增模块，pipeline桥接等先不做，方案之后更新
## 原则
1. 项目代码不要有任何注释，保证代码逻辑通顺简洁，catpaws下的所有类名都需要CW前缀
2. 手机端在xcode上实现，标准需要在md里清晰描述，传递给macos的agent
3. 代码必须模块化，任意文件禁止超过800行代码，命名清晰明了
4. 逐行理解上述要求，有任何歧义必须提出，优先解决歧义，向我提问
