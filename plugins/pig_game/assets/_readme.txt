养猪游戏 · assets 目录说明
====================================================================
一个猪种 = 一个文件夹（配置 + 材质在一起，不堆在别处）
====================================================================

    assets/
      _readme.txt             本文件
      _template/              新猪种模板（_ 开头不会被加载）
        species.json          照抄它

      super_fat/              超级肥猪
        species.json          ← 这个猪种的配置（JSON，直接改）
        image.png             ← 卡片横幅 + QQ 附图
        icon.png              ← 预留小图标（当前未使用）
      flying/                 神奇飞猪
        species.json  image.png  icon.png
      fish/                   鱼猪
        species.json  image.png  icon.png
      gudu/                   咕嘟猪（魔法猪）
        species.json  image.png  icon.png

      scene/                  猪圈场景（没有 species.json，不会被当猪种）
        grass.png   草地
        farm.png    农场
        night.png   夜晚

--------------------------------------------------------------------
怎么改配置
--------------------------------------------------------------------
改对应的 `assets/<猪种id>/species.json`，改完重载插件。

    {
      "id": "gudu",                     ← 唯一 id，别和别的撞
      "name": "咕嘟猪",                  ← 显示名
      "type": "magic",                  ← base=普通猪 / magic=魔法猪
      "aliases": ["咕嘟", "咕嘟魔法猪"],  ← 玩家叫法，越长越优先

      "coin_per_day": 5,                ← 每天产币
      "attack": 15,                     ← 战斗点数
      "steal_rate": 0.0,                ← 被偷成功率 0~1
      "stealable": false,               ← 能不能被偷
      "tradable": false,                ← 能不能交易

      "craft": {"fish": 2, "flying": 1},← 合成配方；普通猪写 null
      "obtain_dates": [],               ← 限定日期 / 时间段，见下

      —— 以下一般不用动 ——
      "team_bonus": 0.15,               ← 魔法猪整队加成（普通猪 0.0）
      "base_price": 0,                  ← 玩家间「交易」的估价基准
      "shop_price": 0,                  ← 「天降猪猪」商店卖多少金币/只（0 = 不上架）
      "trade_count_max": 0,             ← 单笔交易上限
      "death_prob": 0.0,                ← 打卡时死亡概率
      "breed": {"enabled": true, "base_prob": 0.1, "amount": 1,
                "cap": 10, "aff_influence": 0.5}
    }

--------------------------------------------------------------------
限定日期 / 时间段（obtain_dates）
--------------------------------------------------------------------
命中任意一条即放行；空值 `[]` 表示不限时。

    []                          不限时（常驻可合成）
    ["2026-12-25"]              只此一天
    ["12-25"]                   每年 12-25（节日限定）
    ["2026-10-06~2026-12-01"]   ★ 时间段（含首尾两天）
    ["10-06~12-01"]             每年这个时间段
    ["12-25~01-05"]             跨年时间段（冬天这一段）
    ["2026-10-06~"]             从这天起，之后都行
    ["~2026-12-01"]             到这天为止
    ["2026-10-01~2026-12-01", "12-25"]   多条混写，命中任意一条即可

分隔符用 `~`，全角 `～` 和中文「至」「到」也认。

例：咕嘟猪只想在 2026-10-06 到 2026-12-01 之间能合成 ——

    "obtain_dates": ["2026-10-06~2026-12-01"]

不命中时报「是限定款，今天不是它的可获取日期」。

--------------------------------------------------------------------
材质：约定优于配置
--------------------------------------------------------------------
图片放进猪种自己的文件夹就直接生效，**不用写任何路径**：

    assets/gudu/image.png    → 咕嘟猪 自动用它
    assets/scene/grass.png   → 「草地」场景 自动用它

命名规则在 view/render.py：
    猪种图   assets/<猪种id>/image.png
    场景图   assets/scene/<场景id>.png

只有想用别的路径时，才在 species.json 里加：

    "assets": {"image": "别的/路径.png"}

规则：
1. 缺图不报错，自动回退插件卡面 card.png。
2. 比例随意，卡片「居中裁剪」铺满横幅（700:300），绝不拉伸。
3. 建议 1400x600（2.33:1），单张 < 500KB，PNG / JPG 都行。
4. 主体别贴边，卡片圆角 18px 会吃掉四角。

--------------------------------------------------------------------
加一个新猪种 = 4 步
--------------------------------------------------------------------
1. 复制 assets/_template/ → assets/dragon/，改 species.json 里的 id/name/数值
2. 放 assets/dragon/image.png（可选 icon.png）
3. text/commands.py 的 SPECIES_WORDS 补上新名字（长词放前面）
4. 重载插件

懒得手敲？用配置工具（第 1、2、3 步全自动，带图形界面）：

    tool\启动工具.bat          ← 双击这个

界面里可以：新增猪种 / 改数值 / 设限定日期 / 拖图进去自动裁剪 /
体检 / 一键同步词表。详见 tool\说明.txt。

不想开界面也行（命令行）：

    python tool\server.py         起界面（默认 http://127.0.0.1:8756）

--------------------------------------------------------------------
天降猪猪（金币买猪商店）
--------------------------------------------------------------------
玩家指令（前缀 猪猪游戏）：

    天降猪猪                      看货（纵向一行一只，只列能买的）
    天降猪猪 买2只飞猪1只鱼猪       下单，不花体力

卖什么、多少钱 = 各猪种 species.json 里的 `shop_price`（0 = 不上架）。
魔法猪只在 `obtain_dates` 命中的日子才上架，非活动期整个不显示。

限购：每人每个猪种每天 `shop_daily_limit` 头（config.yml，默认 100，0 = 不限）
      跨天自动清零，存在玩家档的 shop_date / shop_bought 里。

    fish       鱼猪       36 币   日产 3
