# Meowlisis 梗库（QQ 插件）

自建「梗的知识库」：记住每条梗的**描述**和**接法**；聊天时召回相关条目，交给**角色自己回复**。插件不发送预设台词。

- 独立实现：只 import 标准库；不 import 主项目代码，也不引用任何参考插件文件；
- 不内置词库：词条都在正式 JSON 文件里，可直接增删；
- 不联网；
- 数据：`character/plugin_data/meme_wiki/user_terms.json`（带 `.bak`）；
- 导出：`character/plugin_data/meme_wiki/exports/*.md`；
- `card.png`：插件卡面（GUI 插件页显示，ComfyUI 生成）。

## 正式数据文件

所有梗（包括内置的 4 条）都在：

```
character/plugin_data/meme_wiki/user_terms.json
```

它是普通的 JSON 列表，插件启动时只读这个文件。
新增/修改可以走 QQ 指令，也可以直接改这个文件（保存后重启/重载，写回时会自动留 `.bak`）。

## 加梗：把描述和接法一起记住

```
Meowlisis梗 啥子 描述：西南官话“什么”，也可能是谐音“傻子” 接法：对方说“啥子”时可以回“你才啥子”“说谁傻子呢”
Meowlisis梗 你只是怕了 描述：对方在激将/说你怂 接法：可以回“这谁不怕”“怕啊，但我不说”
```

也支持换行：

```
Meowlisis梗 哈基米
描述：猫娘，也可以是哈基米哈基米
接法：顺着对方的语气玩，不要解释
```

解析规则：

- `Meowlisis梗` 是触发词；
- 第一个词（到空格/冒号/换行为止，1~16 字）作为**梗名**；
- 后面的 `描述：...` 和 `接法：...` 会被分别记住；
- 没有标签时，整段作为「资料」原样保存，由角色自己理解。

## 查梗：不需要加词，直接转 Markdown

```
Meowlisis查梗
```

把整个 `user_terms.json` 转成 `Meowlisis梗库.md`，**作为 .md 文件**发到当前群/私聊；
本地也留一份在 `character/plugin_data/meme_wiki/exports/`。

```
Meowlisis查梗 啥子
```

只发包含「啥子」的条目，仍然是 Markdown。

## 召回逻辑：角色为什么会“记得”这些梗

**插件不做接梗，也不发预设回复。** 它只负责在聊天时把相关梗找出来，交给角色模型。

### 一条普通消息进来

```
1. 归一化消息
2. 如果像问句（“啥子是什么梗”），取出“啥子”作为查询词；否则用整句
3. 对每条梗算分数：
   - 梗名/别名精确相等            → 1.0
   - 梗名/别名出现在消息里        → 0.95
   - 消息出现在梗名/别名里        → 0.90
   - 否则用字符二元组重合度       → 0~1
4. 分数 ≥ recall_threshold（默认 0.45）的条目，按分数取前 recall_top_k（默认 3）条
5. 把这几条的【描述 + 接法】拼成资料，和角色人设、最近几轮对话一起交给角色模型
6. 角色模型自己生成回复，插件只负责发送
```

### 例子：对方说「啥子」

库里：

```
啥子
  描述：“傻子”的谐音
  接法：别解释方言，按谐音接
  别名：傻子
```

处理：

```
消息：啥子
→ 召回：梗名“啥子”精确命中（1.0）
→ 角色看到的资料：啥子 / 描述 / 接法
→ 角色自己决定怎么回（可能回“你才啥子”，也可能回别的）
→ 插件发送角色生成的回复
```

对方说「你说啥子」也能命中（梗名出现在消息里，0.95）；说「你只是怕了」命中另一条；
说「今天吃什么」和库里重合度低，**不召回**，直接返回主链路，由原来的 QQ 回复逻辑处理。

### 例子：别人提到「舞萌」

内置 `awmc` 的别名是 `舞萌` / `maimai`，所以：

```
消息：今天舞萌打得好爽
→ 别名“舞萌”出现在消息里 → 0.95
→ 角色看到 awmc / 描述“唉舞萌痴迷” / 别名“舞萌、maimai”
→ 角色自己决定怎么接
```

不需要说 `awmc`，只要句子里出现「舞萌」或「maimai」就会召回；同理「啥子」的别名「傻子」、
「艾草」的别名「挨操」也会触发。

### 为什么不是插件直接回

本项目插件 API 没有「回复前注入上下文」的钩子。要让角色“记住”这些梗，插件只能在召回后
调用角色模型（`ctx.prompt` 取人设 + `ctx.llm` 生成），再把角色生成的回复发出去。
回复内容不是预设的，是角色按人设现写的；不召回时插件完全不接管。

## 帮助

```
Meowlisis梗 help
```

回一段简短指令说明；`帮助` / `?` / `用法` / `说明` 也行。

## 删除

```
Meowlisis梗删除 啥子
```

仅 `admin_qqs` 里的 QQ 号；留空 = 删除关闭。

## 配置

`plugins/meme_wiki/config.yml` 首次加载自动生成，GUI 插件页也能改：

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总开关 |
| `add_prefix` | `Meowlisis梗` | 加梗触发词 |
| `query_prefix` | `Meowlisis查梗` | 查梗触发词 |
| `recall_threshold` | 0.45 | 召回阈值，越高越保守 |
| `recall_top_k` | 3 | 最多召回几条 |
| `history_rounds` | 6 | 带给角色的对话轮数 |
| `max_desc_chars` | 500 | 单条梗字数上限 |
| `max_reply_chars` | 120 | 角色回复上限 |
| `cooldown_seconds` | 8 | 两次召回生成的最小间隔 |
| `allow_add` | all | all / admin / off |
| `admin_qqs` | [] | 删除权限 |
| `max_entries` | 5000 | 条数上限 |
| `reply_with_at` | false | 群聊回复是否 @ |
| `write_memory` | true | 召回回复是否写短期记忆 |

## 范围限制

- 私聊：全部消息；
- 群聊：现有插件钩子只在 @ / 关键词 / 续聊时调用，普通群聊看不到；
- 不处理图片、文件、语音；
- 没有 WebUI 编辑页，用 QQ 指令或直接改 `user_terms.json`。
