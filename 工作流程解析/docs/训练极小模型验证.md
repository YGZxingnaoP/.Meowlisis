# 训练极小模型验证方案（V0 · 最小可行）

> 出处：对齐 `docs/PLAN_框架与模型训练.md` 的 **Part B（B1 δ-mem / B2 每用户矩阵）**。
> 目的：用**最小代价**验证一个假设 ——
> **冻结的极小基座 + δ-mem 旁路 + 两套 LoRA（思考步用 / 输出步用）分离，能被训练，并让记忆真正进入注意力（而不是塞 prompt）。**
> 本文只讲 V0 该做什么：**用什么底模、框架怎么搭、怎么判成败**。

---

## 0. 一句话
**在单张 24G 上，用 1.7B 基座跑通"δ-mem 注入注意力 + 两套 LoRA（思考步/输出步）分离"的最小闭环，拿到 no-context 增益。**

---

## 1. 要验证什么（四条 Go/No-Go 门）

| 门 | 问题 | 通过标准 | 失败后果 |
|---|---|---|---|
| **G1 能训** | 改造后能收敛、状态稳定、**只有旁路有梯度** | loss 下降；`‖S‖` 有界；backbone `.grad=None` | 停：改实现 |
| **G2 记忆进注意力** | **no-context**：删历史明文只留 `S`，还答得对吗 | 显著 > 无 `S` 基线 | 停：记忆没进注意力 |
| **G3 有效** | 同模型 `+δ-mem` vs `−δ-mem` | 记忆子集有提升 | 降级为工程方案 |
| **G4 参数分离** | 两套 LoRA（**思考步用** / **输出步用**）能各自独立训练、互不干扰 | 各自 `.grad` 正常；切换 LoRA 后另一步输出不受影响 | 退回单套（不做分离） |

> G1/G2 是**生死门**；G3/G4 决定要不要放大投入。全部通过 → 框架成立。

## 2. 底模选型（具体到型号）

| 层级 | 底模 | 参数 | 单卡 24G | 用途 |
|---|---|---|---|---|
| 冒烟 | **Qwen3-0.6B** | 0.6B | 轻松 | 只验证管线/改造能跑，**不看效果** |
| **主验证** | **Qwen3-1.7B** | 1.7B | bf16 ~16–20G | **本次主角**：极小有效性 |
| 对标 | **Qwen3-4B-Instruct** | 4B | QLoRA/ZeRO-2 ~24–40G | 复现论文（同基座，可直接比数字） |

**推荐：主验证用 Qwen3-1.7B；对标用 Qwen3-4B-Instruct。**

选型理由：
- **为什么 Qwen3 系**：中文强；HF/PEFT/DeepSpeed 支持成熟；**δ-mem 论文已在 3B–8B 上验证**（Qwen3-4B-Instruct 46.79%→51.66%，SmolLM3-3B 26.08%→34.94%），有现成对标。
- **为什么 1.7B 而不是 0.6B**：0.6B 太弱，记忆增益会被噪声淹没；1.7B 是"能收敛 + 快迭代"的甜点。
- **为什么留 4B 对标**：论文基线就是它，可**直接对照 +4.87pt**，判断你实现对不对。

## 3. 框架怎么搭

### 3.1 架构（单骨干 + 两套独立 LoRA + 共享记忆）
```
冻结 Qwen3-1.7B（φ，永久不训）
 ├─ δ-mem 旁路（可训练）：每层 S∈R^{r×r}, 投影 Wq^m,Wk^m,Wv^m,Wb,Wdq,Wdo
 ├─ LoRA_think（可训练）：只在"思考步"前向时挂载
 ├─ LoRA_talk （可训练）：只在"输出步"前向时挂载      ← 与 LoRA_think 参数不重叠
 └─ 记忆状态：S（V0 先单用户、单槽；V1 再上 per-user/MSW）
```
- **思考步**：`y = φ(x) + Δφ_think(x)`（只挂 `LoRA_think`）
- **输出步**：`y = φ(x) + Δφ_talk(x)`（只挂 `LoRA_talk`）
- 基座冻结、记忆状态 S 共享；**只有这两套 LoRA 参数彼此不相交**。
> **V0 极简原则**：先只挂 **一套 LoRA** 把 δ-mem 跑通（G1/G2），**再加第二套 LoRA** 并验证"两套能各自独立训练"（G4）。

### 3.2 模型改造（核心，必须自研）
δ-mem 要改**注意力前向**，标准推理引擎（llama.cpp / 默认 vLLM）**不暴露隐藏状态 → 做不到**。

替换 Qwen3 每层 attention 为 `DeltaMemAttention`：
```python
class DeltaMemAttention(OriginalQwen3Attention):
    def __init__(self, cfg, r=8, alpha=16):
        super().__init__(cfg)
        h = cfg.hidden_size
        self.Wq_m = nn.Linear(h, r, bias=False); self.Wk_m = nn.Linear(h, r, bias=False)
        self.Wv_m = nn.Linear(h, h, bias=False); self.Wb  = nn.Linear(h, 1)
        self.Wdq  = nn.Linear(r, h, bias=False); self.Wdo = nn.Linear(r, h, bias=False)
        self.register_buffer('S', torch.zeros(r, r))     # 在线记忆状态
        self.r, self.alpha = r, alpha

    def forward(self, x, **kw):
        qm = F.normalize(torch.tanh(self.Wq_m(x)), dim=-1)
        km = F.normalize(torch.tanh(self.Wk_m(x)), dim=-1)
        vm = self.Wv_m(x); beta = torch.sigmoid(self.Wb(x)); lam = 1 - beta
        # ---- 读：低秩修正 ----
        res = qm @ self.S                                   # [B,T,r]
        dq  = self.Wdq(res); do = self.Wdo(res)
        scale = self.alpha / self.r
        # ---- 注入 q / o 两分支 ----
        out = self._attn_with_injection(x, dq, do, scale)   # 改写原 attn
        # ---- 写：门控 delta ----
        kv = vm - (km @ self.S)
        with torch.no_grad():                               # V0: 状态更新不进梯度
            self.S = (lam.mean(0,keepdim=True) * self.S
                      + beta.mean(0,keepdim=True).T @ (kv.mean(0,keepdim=True)))
        return out
```
要点：
- 注入公式：`q' = q + (α/r)·dq`，`y' = Attn(q',K,V) + (α/r)·do`。
- **V0 把 `S` 更新放 `no_grad`**（消融再决定是否反传）。
- 只训 `Wq^m…Wdo` + 两套 LoRA（思考步/输出步）；**backbone 全冻结**。

### 3.3 训练栈
| 项 | 选择 | 依据 |
|---|---|---|
| 框架 | PyTorch + `transformers` + `peft`(LoRA) | 必须能改 attention |
| 分布式 | **DeepSpeed ZeRO-2** | δ-mem 论文同款 |
| 优化器 | **fused AdamW** | 论文同款 |
| 精度 | **bfloat16** | 论文同款 |
| 学习率 | **峰值 2e-4，cosine + warmup** | 论文同款 |
| δ-mem 超参 | `r=8`（论文取 4，先 8 稳），`α=16`，**q/o 分支**，**全层** | 论文默认 |
| LoRA | rank 8–16，q/v_proj | 轻量 |

### 3.4 推理栈（V0 先简单）
- **先用 HF `generate` + 改造后的模型**跑通（能拿 `S`、能保存/加载状态即可）。
- 性能不够再上 **vLLM 自定义 attention 插件**；**不要用 llama.cpp**。

## 4. 最小数据集（V0）

从现有资产构造，**先小后大**：
```
输入源（复用现成，不改语义）：
  character/memory/*.txt                     → (user, time, text)
  character/abstract_memory/meow-*.json      → 记忆条目 C（event/tags/topics）
  character/info/users_info/*_latest.json    → 用户档案（S_0 初始化 / 门控键）
样本格式：{user_id, history[], query(Q), response(Y), memories(C)}
```
- **训练集**：2k–5k 条即可（V0 探路）。
- **评测集**：**200 条 no-context 测试**（先删 `C` 明文问 `Q`，再只留 `S` 问）。
- 按**时间后 10%** 验证，避免同用户泄漏。

## 6. 评测与判定

| 指标 | 怎么测 | 目标 |
|---|---|---|
| **no-context 准确率** | 只留 `S`，不问历史 | **G2：> 无 S 基线** |
| 记忆召回率 | 该用的记忆是否影响输出 | 上升 |
| 焦点命中率 | 回复是否只落在 focus | 上升 |
| 通用不退化 | 闲聊抽样 + 小模型裁判 | 基本持平 |
| 效率 | 显存 / 吞吐 / 延迟 | 增量可接受 |

## 8. 风险与对策
| 风险 | 对策 |
|---|---|
| 1.7B 太弱、增益被噪声淹没 | 先 4B 对标确认真有信号，再回 1.7B |
| `S` 数值爆炸/漂移 | `‖S‖` 上界 + l2norm + 可回滚到 `no_grad` 更新 |
| 记忆没进注意力（G2 失败） | 检查注入分支/深度；确认 `Q` 不带明文 `C` |
| 改造后不收敛 | 先只开 q 分支、中层；逐步加 |
| 4B 单卡放不下 | QLoRA 4bit + ZeRO-2 |
| 评测失真 | **P0 先建基线**，没有基线不训 |
