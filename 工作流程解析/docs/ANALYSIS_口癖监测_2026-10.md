# 口癖（LLM 固有用语习惯）的发现与监测

> 本文回答的是**另一个问题**：不是"哪些词算水"，而是"模型自己反复用的那些说法怎么被发现、怎么被持续监测"。
> 上一版 `ANALYSIS_水词与打分体系_2026-10.md` 只测了"固定词表覆盖了多少字"，那一套**对发现口癖无效**——是我把问题窄化了。
> 数据：`character/memory/*.txt` 49 个日文件（8/18–10/23），AI 5353 条 / 410,117 字；人类侧 4781 条 / 152,290 字（同一段对话的另一半，作为域内基线）。**仅分析，未改任何代码。**

---

## 0. 先把方法错误摆清楚

你说得对的地方，用数据讲：

| 你的例子 | 字面子串次数 | 真实情况 |
|---|---|---|
| `我认` | 73（69 条消息） | 拆开看：`我认真` 22、`我承认` 11、`我认识` 6、`我认输` 1、`我认得` 1、`我认了` **5** —— 真正算口癖的只有个位数 |
| `我接` | 26 | 里面混着 `我接口`（"拿 Postman 调我接口"）、`我接住`，真正的口癖是 `我接得/我接一句`（唱接龙） |
| `白说` | 3 | 几乎不存在于本语料 |
| `这招真狠` / `真狠` | 5 / **0** | 不存在 |
| `揽` | **2**（`往身上揽` 只在 2 条消息里） | 不存在 |
| `撑` | 52 | 其中 `硬撑` 25 —— 口癖不是"撑"，是"硬撑"这个**劝阻动作** |
| `第一步` | **0** | 不存在 |

三条结论：

1. **子串匹配会把口癖和同形词一并抓走**（`我认` 命中 73，真口癖只有 5）。固定正则连"我知道哪个是口癖"都表达不了，因为它没有**词边界**概念，也没有**基线**概念。
2. **你举的多数例子在本语料里几乎为 0**，这恰恰说明口癖是**模型选择+时间演化**的产物：它不写在你事先能编的词表里，而且换了模型/换了时期就换一批。
3. **口癖的单位不是"词"，是"搭配/框架/交际动作"**：`硬撑`、`不然我就`、`你倒是说`、`我记着呢`——这些是多字框架，而且是**可变形**的（`硬撑/硬撑着/别硬撑/还硬撑` 是同一个族）。

## 1. 为什么"固定词表 + 正则"在这里结构性失效

### 1.1 规模上不成立

| 阈值（覆盖多少条不同回复） | 4 字片段条数 |
|---|---|
| ≥2 条 | 25,957 |
| ≥3 条 | 9,605 |
| ≥5 条 | 3,252 |
| ≥8 条 | 1,311 |
| ≥12 条 | 636 |
| ≥20 条 | 230 |
| ≥50 条 | 33 |

AI 侧去重 4 字片段共 **274,677** 个。想"覆盖全部口癖"要维护上千条；而够格叫口癖的不足 200 条——**你不知道是哪 200 条**，这正是问题。

### 1.2 口癖有"世代更替"，词表永远滞后

各口癖族的月度频次（每百条回复）：

| 族 | 8 月 | 9 月 | 10 月 | 趋势 |
|---|---|---|---|---|
| 施压反问（你倒是/是不是又/是想让我…） | 4.4 | 7.5 | **9.9** | ↑ 涨 2.2× |
| 元话语（话说回来/你说得对/这话说） | 1.6 | 3.3 | **5.9** | ↑ 涨 3.7× |
| 劝阻关心（硬撑/别又/别急） | 5.2 | 6.9 | **8.4** | ↑ |
| 服软认输（我认了/糊弄/我又不是） | 1.4 | 2.6 | **3.2** | ↑ |
| 傲娇强调（我可要/我才不/我可没） | **10.4** | 4.4 | 2.3 | ↓ 掉 4.5× |
| 转折铺垫（不过既然/不过嘛/不过你） | **9.6** | 2.5 | 1.6 | ↓ 掉 6× |
| 戏谑条件（不然我…/这还差不多） | **9.0** | 2.5 | 1.1 | ↓ 掉 8× |

**旧的在死、新的在长**。任何"人工列词表"都是在给上一代口癖立碑：等你把它写进 json，它已经在退潮；而正在涨的那一代你还没意识到。

### 1.3 口癖不能"删"

词表那套是**删除**逻辑，但口癖是**语义骨架**：

| 原句 | 删掉口癖字 | 结果 |
|---|---|---|
| 我认了 | 我**认了** → 我了 | 不成句 |
| 别硬撑 | 别**硬撑** → 别 | 不成句 |
| 别又熬夜 | 别**又**熬夜 → 别熬夜 | 意思变了（"又"是在记账） |
| 不然我就… | 不**然我就**… | 不成句 |
| 你倒是说啊 | 你**倒是**说啊 → 你说啊 | 施压消失，语气全变 |

**口癖是"用词偏好"，不是"冗余填充"。** 处理它只有三条路：抑制（换说法）、配额（限次数）、接纳（当人设）。没有一条是"删字"。

## 2. 该怎么做：无监督发现 + 在线度量

核心思路：**不猜词，测分布**。口癖的统计本质是两件事——

1. **相对基线过度使用**（人类不这么说，它天天说）；
2. **自我重复**（跟它自己前面说过的话高度重合）。

这两件事都可以在**不知道具体是哪个词**的情况下算出来。

### 2.1 发现管线（离线，跑在历史上）

```
① 切分      每条回复 → 子句；子句 → 字级 4-gram + 词级 1~3-gram
② 文档频次  每个片段覆盖了多少条不同回复（df）——过滤"一条消息里刷屏"的假高频
③ 基线对比  lift = (df_AI / N_AI) / (df_人类 / N_人类)     ← 域内人类侧当分母
④ 稳定度    出现天数 / 消息数（b/t）：低=短期梗，高=长期口癖
⑤ 突发度    最近 3 天内的占比：高=刚学会的新口癖（"正在流行"）
⑥ 位置画像  片段落在句首/句中/句尾的比例（功能不同：句首=转折施压，句尾=收束讨债）
⑦ 词族聚合  按共有实词字归并（撑：硬撑/硬撑着/别硬撑/还硬撑 → 一个族）
⑧ 人工命名  只对通过 ②~⑦ 的候选命名/归类（人只做最后一步，不做发现）
```

### 2.2 两个"不需要词表"的在线指标（可直接接进现有链路）

**指标 A：自重复率**——本条回复的 4-gram 里，有多大比例在过去 K 条自己说过的话里出现过。

| 窗口 | mean | median | p90 | p99 |
|---|---|---|---|---|
| K=5 | 0.029 | 0.000 | 0.078 | 0.333 |
| K=20 | 0.048 | 0.019 | 0.120 | 0.459 |
| K=50 | 0.065 | 0.034 | 0.153 | 0.536 |
| K=200 | 0.099 | 0.066 | 0.216 | 0.683 |

**指标 B：惊奇度**——本条回复里"整个语料第一次出现"的 4-gram 比例：mean **0.806**、median 0.837、p10 0.648。这个指标能反过来用：**p10 那批（<0.65）就是最模板化的一批回复**。

> 注意一个坑：自重复必须**剔除与用户上句重合的部分**。用户说"屏幕"，模型回"屏幕"不算口癖；同一个人设反复说"你倒是"才算。实现上：先减去与最近 N 条用户消息的交集。

**指标 C：口癖负载**——已知族在一条回复里命中几个（按前 10 族统计：62.5% 的回复 0 族，27.8% 1 族，9.4% ≥2 族，平均 0.49 族/条）。这是最省事、最可解释的"观感指标"。

### 2.3 口癖 / 梗 / 人设词，要分开算

| 类型 | 判据 | 例子 | 该不该管 |
|---|---|---|---|
| **口癖（真问题）** | 跨 30+ 天稳定、人类侧 lift 高、可迁移到任何话题 | 你倒是(114)、别又(177)、不然我(148)、本喵(343) | 管（抑制/配额） |
| **短期梗（关系资产）** | b/t 低（几天内爆发后消失），与某个话题绑定 | 键盘上踩乱码(43)、木头人偶(21，1 天)、金苹果藏馆(25，2 天) | 不管（是共同记忆） |
| **人设词（基座）** | 出现在设定里、人类侧也有或为角色必需 | 主人(3911)、喵(2486)、小鱼干(777) | 不管（删了掉人设） |
| **共享语域** | 人类侧同样高频 | 看屏幕（人类 280 次 vs AI 198） | 不管（两人都这么说） |

**"看屏幕"这条尤其能说明基线的重要**：AI 说 198 次看着像口癖，但人类侧说了 280 次——这不是模型的习惯，是这个场景的语域。

### 3.1 这些数字读起来是什么意思

- **口癖自成"句型"，不是零散的词**：句首型（施压/转折/自称/条件）负责**起手定调**，句尾型（元话语/讨债/服软）负责**收尾落锤**。这解释了为什么"删词"会让句子塌：你删的是那个位置的**功能件**。
- **每千字 7.0 次口癖命中**（11 族合计 2,881 次 / 410k 字）。看着不高，但口癖是**低频高辨识**的东西：一条 70 字的回复里出现一次"你倒是说啊"，整体观感就变了一个人。
- **`本喵` 343 次 vs `主人` 3911 次**：`主人` 是称呼（人设），`本喵` 是**自我指称的口癖**——模型在"我"和"本喵"之间选择，选本喵的次数够多就成了标志。这属"该不该管"里最难的一类：它同时是人设资产和重复源。

## 4. 建议怎么改（分层，未实施）

### L0 · 先建"口癖仪表盘"（不动生成链路，只观测）

每轮落盘：`4-gram 集合摘要`、`自重复率(K=20/50/200)`、`惊奇度`、`命中的已知族`、`与用户上句的重合率`。
每周产出一张榜：**新出现的 4-gram（3 天内 df 增长 ≥5 且人类侧 lift ≥3）**，进人工审阅队列。

> 这是替代"手工加词"的唯一可持续路径：人每周只审 10~20 条，而不是靠想象去写词表。

### L1 · 把"自重复/惊奇度"接进打分，替代 `W/L`

现打分是 `100 - 水词占比×100 - 长度罚`，实测水词项只占 5.7 分、长度项占 25.3 分（见上一份文档）。
建议改成三项相乘/相加的形式：

```
score = a·(1 - 自重复率_去用户重合) + b·惊奇度 + c·(长度合规度) - d·口癖负载
```

- `自重复率`、`惊奇度` 都**不需要词表**，天生能跟上口癖换代；
- `口癖负载` 用已知族做可解释的补充；
- `长度合规度` 保留（因为长度是真实问题），但改成**相对用户消息长度**而不是绝对 20 字。

### L2 · 干预方式：配额，不是删除

| 手段 | 适用 | 做法 |
|---|---|---|
| 配额 | 高频族（本喵/你倒是/别又/不然我） | 提示词里给预算："每 10 轮内'本喵'不超过 2 次"；后处理检测超量时**换说法**（本喵→我）而非删字 |
| 换说法表 | 句首起手（你倒是/不过既然/不然我） | 维护"同一功能的 N 种说法"，轮换使用，降低单点重复 |
| 冷却 | 突发型（3 天内暴涨的新口癖） | 检测到 burst 就加入 24h 内禁用清单，先压住，再人工判断 |
| 接纳 | 人设核心（主人/喵/小鱼干） | 不干预，只统计 |

### L3 · 语义层：n-gram 抓不到的"同义口癖"

同一交际动作换着词说（劝主人别硬撑 / 别撑 / 别逞强 / 别顶着），n-gram 会当成三种。要抓这类得用**句向量聚类**（配置里已有 `qwen3.7-text-embedding`）：

- 把每条回复的"动作句"切出来做 embedding；
- 按簇统计频次与月度趋势；
- 簇内高频 + 人类侧稀少的簇 = 语义口癖。

这一步放在 L0/L1 稳定之后再做，成本高但能覆盖最后一层。

## 5. 局限（这些结论的边界）

1. **人类基线是单一用户 + 语音转写**：ASR 会吞字、断句，`lift` 分母偏噪。理想分母是"通用中文口语语料"，本次用 jieba 内置新闻词表做了第二分母，但那是书面语。
2. **语料只覆盖桌面语音链路**：QQ 群/弹幕/直播不在这些 txt 里，那边的口癖结构与长度约束完全不同（那边有 16~20 字硬约束）。
3. **字面口径的族划分是人做的**：族名和变体表是我按统计结果归并的，属于"发现之后的人工归纳"；发现过程本身（df/lift/b/t/burst）不含人工词表。
4. **4-gram 有长度盲区**：多字的框架（"不然我可就不客气了"）会被切成几个 4-gram，需要用词级 1~3-gram 补充（本文第 3 节两个口径都用了）。
5. **`本喵` 这类介于人设与口癖之间的项，判据是"人类侧为 0 且在提示词里没有"**——如果设定里本来就写了"自称本喵"，那它就该归人设、不该进配额。

## 附录 · 复现口径

| 项 | 定义 |
|---|---|
| 字面次数 | 对 AI 消息做 `str.count`，重叠计（如 `硬撑着` 计入 `硬撑`） |
| 覆盖消息数 | 至少出现 1 次的回复条数 |
| 人类侧 | 同一批日志里非 `喵利呜西斯` 的消息 |
| 4-gram | 去掉标点与空白后的相邻 4 字 |
| df | 该片段覆盖的不同回复条数 |
| lift | (df/N_AI)/(df_human/N_human)，人类侧加 0.5 平滑 |
| b/t | 出现天数 / 覆盖消息数：低=短期梗，高=长期口癖 |
| burst | 任意 3 天窗口内出现量占总量比 |
| 自重复率 | 本条 4-gram 中出现在过去 K 条 AI 回复里的比例（未剔除用户重合，实现时需剔除） |
| 惊奇度 | 本条 4-gram 中此前全语料未出现过的比例 |
