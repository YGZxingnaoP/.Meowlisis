## 一、项目陈述（数字已填实）

历经近 3 个月的开发、1 年的经验积累，从最开始的 MiaoWuCat 到 Meowlisis：首字延迟从 45 秒降低到稳定 5 秒、最快 2 秒；功能上实现了记忆算法、TTS、ASR、QQ 聊天、智能搜索、插件系统、主动回复、网页自浏览等；代码从魔改走向原创——主框架下代码量 **62,280 行**（有效代码 51,280 行）、函数 **3,491 个**、类名 **464 个**、模块 **543 个**（含 100 个可导入子包、`func/` 下 19 个一级功能域）；结合副项目及 GitHub 开源项目魔改整合，代码量 **1,131,926 行**（1,307 个代码文件）、函数 **11,568 个**；结合环境模型、研发报告、资源文件，整包容量达 **37.48 GB**（124,273 个文件）；前端设计代码量 **16,292 行**（JS 12,554 / CSS 2,980 / HTML 758，420 个 JS 函数）；开发期仅可统计的纯手写完善代码提示词就达 **8 万字**，其余提示词和调试过程难以统计。

## 二、应用层技术：从输入到输出、从主干到分支

应用层技术总体沿「先接触现成实现、再拆成可控模块」的路径推进：语音输入从运行 SenseVoice 的现成推理 demo 起步，到自建 2pass 流式识别客户端——麦克风、扬声器回环、手机注入三路独立会话各自维护 VAD 能量阈值、声纹相似度匹配与打断判定，并补齐断线重连、热词替换与 itn 数字归一；语言层从直接调用 DeepSeek / Qwen / Gemini 的 chat completions，到自组动态提示词（角色卡、价值观、用户档案、日期、记忆摘要与条件块按需拼入）、消息清洗排队与流式分句，并以 Trie 前缀树加 EWMA 平滑打分实现水词的三档流式清洗；决策层从按工具调用协议手写分支，到自建 toolbox 触发式工具注册表、QQ 链路独立意图分析与导演式主动回复（规划—推进—收尾，附预期反应与失败退路），再由 MeowPsyche 心理状态机与情绪标签共同约束输出；记忆层从调用向量库的增删查，到实现短期按类型裁轮、长期按天落盘、按月结构化摘要、用户档案与价值观独立维护的四层结构，并以 jieba-BM25 叠加标签、实体、月份、话题五路召回、RRF 融合、证据分双半衰期衰减与临时承诺回收；输出层从跑通 GPT-SoVITS v2Pro 官方推理脚本，到自训音色权重、按情绪强度映射参考音频与采样参数、按静音点切分做流式合成、在播放层接受实时打断，并借 GPU Graph 思路压缩推理开销，使首字延迟由 45 秒收敛至稳定 5 秒、最快 2 秒。

主干之外的技术按需挂载为分支：QQ 从研读 OneBot v11 协议，到自写 NapCat 客户端与群聊协调（合并窗口、续聊判断、冒泡插话、主动发送、表情与戳一戳）；检索从抓取单个网页，到自建请求—解析—质量判定—摘要回灌的搜索 agent 与多类爬虫，并将网页自浏览组织为候选过滤、抽帧、视觉概括、素材沉淀的流水线；视觉从调用在线多模态接口，到自设计截屏、画面变化检测、理解与写记忆的观看闭环；绘画从手动操作 ComfyUI，到自生成标签与画布规格、内容审查与画板服务；音乐从以 RVC 跑通单曲，到自建三轨分离、变声、混音链路与基于 F0 提取和滑窗余弦对齐的哼唱定歌接龙；表演从照 VTube Studio 协议发消息，到自做情绪到表情、口型与身体摆动的映射；手机操控从跑通 WebDriverAgent，到自建意图判断、操作下发与流程沉淀的操作链路；直播从套用弹幕库示例，到自建双通道接入、朗读、礼物致谢与主动发送；工程侧从手动改配置，到自建插件系统（main 与 qq 双通道）、带 i18n 的 Web 配置面板与内置运行时的整合包。

## 三、数据来源与口径

1. **行数**：文件物理行数；「有效代码」剔除空行与整行 `#` 注释（Python）/ `//`、`/* */` 注释（JS/CSS）。
2. **函数/类**：Python 用 `ast` 解析，统计 `FunctionDef` / `AsyncFunctionDef` / `ClassDef`（含嵌套、含 `__init__`）；前端函数为正则统计 `function` + 箭头函数 + 类方法，会略偏保守。JS/TS 上游工程（如 NapCat）不计函数，故 11,568 是「Python 函数」口径，实际函数更多。
3. **开源整合行数**：统计整包内上游源码行数（`node_modules`、`__pycache__`、构建产物已排除），代表「整合进整包的代码规模」，不等于逐行审核过的改动量；自研与上游已分列，避免混算。
4. **容量**：按 1 GB = 1024³ 字节计（故 37.48 GB ≈ 38,381 MB），与「37g」表述一致。
5. **提示词 8 万字**：开发期驱动 AI 写码/改码的可统计部分，为手写统计口径，非仓库内可复算项；仓库内可复算的是运行期提示词文本 13.7 万字。
6. **首字延迟 45s → 5s / 2s**：端到端口语对话实测（LLM 首字 + 首块合成 + 播放），非实验室基准，随模型与机器波动。

> 原始统计脚本：`$env:TEMP\count.py`、`vendor.py`、`packages.py`（一次性脚本，按工作区约定不落在项目目录）。
