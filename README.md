### LLM调用
LLM调用分为工具调用和正常对话
正常对话:
 - 支持Qwen，Deepseek和ollama本地的模型调用
 - 可以在前端配置界面配置```apiKey```, ```temperature```, ```max_token```的基础数值，必须开启流式```你也改不了，嘿嘿```
```没有考虑支持多模态一次性搞定语音，视觉理解和角色扮演的打算！一是太贵了，二是经过实践，多模态模型的角色扮演能力性价比不高```

工具调用：
 - 支持Qwen，GLM和Kimi平台的多模态工具调用
 - 多模态模型和正常对话以及视觉模型完全独立，如果需要实现所有功能，需要独立的```apiKey```, 以及其它必要配置

提示词：
 - 可以在配置文件里配置提示词，模板我就不提供了，描述清楚详细即可，不建议超过1000字
 - 提示词使用system_prompt发送给AI大语言模型，用户输入通过user_propmpt传递
 - 可以设置多个提示词，按照概率发送，对应小猫的不同性格
```
作者的话：
一个人的性格是复杂的，不是一份提示词能完全概括的，就算全写进一个提示词，普通的llm也无法很好的理解，所有做了这个性格会改变的功能。
其次，这个项目没有考虑支持多ai智能体的互动！
但是吧......或许这个功能有很多其它玩法。
```


### 语音识别
语音识别功能分为直接语音输入识别功能，电脑扬声器声音采集，和Websocket音频传递
语音输入识别：
 - 支持极为简单的噪声过滤，简单来说就是声音太轻就不检测了，可以配置和关闭
 - 基于Sensevoice的魔改，已经内置了该功能，可以在配置文件打开
 - 支持声纹检测，支持多声纹记录，可以配置相似度检测阈值
 - 支持流式合成，不支持情绪识别！（但是可以传递音量和关键词识别的简单情绪打标，事实上……不建议打开）

电脑扬声器采集：

### 语音合成
基于古老的GPT-Sovits(_v2_pro )的精简，已经内置了该功能，可以在配置文件打开
功能介绍：
 - 支持正常GPT-Sovits的v2pro版本的基本语音合成功能
 - 支持不同情绪对应不同参考音频，情绪识别的原理是llm决策的情绪标签，然后通过后端处理，举个例子；
    你听到的格式：```主人，你真是太坏了```
    LLM实际发送过来的是：```[生气]\n主人，你真是太坏了```
    ps:如果觉得功能不稳定，可以在配置界面关闭
 - 实施打断 施工中。。。

### 视觉模块
支持在线调用API和本地小模型的调用
在线API：
 - 目前只支持Qwen的视觉理解，概括图片内容，然后作为用户消息发送给llm模块解析使用
 - 通过关键词触发和Tools的决策使用可以调用视觉模块
