### LLM调用
LLM调用分为工具调用和正常对话
正常对话:
 - 支持Qwen和Deepseek的模型调用
 - 可以在前端配置界面配置```apiKey```, ```temperature```, ```max_token```的基础数值，必须开启流式```你也改不了，嘿嘿```
```
没有考虑支持多模态一次性搞定语音，视觉理解和角色扮演的打算！一是太贵了，二是经过实践，多模态模型的角色扮演能力性价比不高
```

工具调用：
 - 支持Qwen，GLM和Kimi平台的多模态工具调用
 - 多模态模型和正常对话以及视觉模型完全独立，如果需要实现所有功能，需要独立的```apiKey```, 以及其它必要配置

提示词：
 - 可以在配置文件里配置提示词，模板我就不提供了，描述清楚详细即可，不建议超过1000字
 - 提示词使用system_prompt发送给AI大语言模型，用户输入通过user_propmpt传递
 - 可以设置多个提示词，按照概率发送，对应小猫的不同性格
```
作者的话：
一个人的性格是复杂的，不是一份提示词能完全概括的，就算全写进一个提示词，普通的llm也无法很好的理解，所以做了这个性格会改变的功能。
其次，这个项目没有考虑支持多ai智能体的互动！
但是吧......或许这个功能有很多其它玩法。
```


### 语音识别
语音识别功能分为直接语音输入识别功能，电脑扬声器声音采集，和Websocket音频传递
语音输入识别：
 - 支持极为简单的噪声过滤，简单来说就是声音太轻就不检测了，可以配置和关闭
 - 基于Sensevoice的魔改，已经内置了该功能，可以在配置文件打开
 - 支持声纹检测，支持多声纹记录，可以配置相似度检测阈值
 - 支持流式合成，不支持情绪识别！

 - 支持不同情绪对应不同参考音频，情绪识别的原理是llm决策的情绪标签，然后通过后端处理，举个例子；

## Vtuber皮套
通过 VTube Studio 的 WebSocket 接口驱动 Live2D 皮套，支持情绪→表情映射、身体摆动与口型同步，对应 func/vts 模块。

## Bilibili直播api兼容
接入 B 站开放平台弹幕协议（blivedm），支持弹幕读取、主动发弹幕、礼物感谢与 SC 回复，可在配置界面扫码登录。

## 点歌
MeowSinger 点歌模块，通过关键词或前缀触发，调用网易云音乐搜索并播放歌曲，支持歌词同步字幕。

## 翻唱
基于 RVC 的翻唱模块，支持指定模型与特征索引进行翻唱，对应 .RVC 服务。

## 每日提醒
待办提醒模块，读取 character/backlog 下的待办事项，按设定时刻主动提醒，支持直播端与 QQ 双通道。

## 节日祝福
节日/生日/节气祝福模块，按公历、农历、24 节气与浮动节日自动生成祝福文案。

## 主动聊天
空闲主动回复核心，支持冷却计时、原创话题与继承话题，让角色在无人互动时主动开口。

## 记忆整理
抽象记忆、用户记忆与长期记忆等多层记忆协同，定时摘要与整理，持续优化中。

## 网页浏览
主动浏览 B 站内容，自动截帧、筛选话题并生成摘要，支持缓存与收藏。

## 视频理解
MeowVision 视觉模块，支持屏幕截图、画面裁剪与变化检测，调用多模态模型理解画面。
