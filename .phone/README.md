# 喵呜手机界面（.phone）

不改原项目的独立手机端：手机浏览器打开网页，看桌宠 + 直接语音说话。

## 原理

- `.phone/serve.py` 起一个独立 HTTPS 服务（端口 8443）：
  - 提供手机页面（`static/`）
  - 把 `.desktopet` 目录暴露为 `/pet/`，供 iframe 加载桌宠（同源，避免混合内容）
  - 反向代理到主程序 `api.py`（127.0.0.1:1800），解决手机端跨域
- 手机页面「按住说话」：浏览器采集麦克风 → 重采样为 16k 单声道 int16 PCM → 转发到主程序 `/audio/send` → SenseVoice 识别 → LLM。
- 手机页面也可打字，走 `/chat`；AI 回复文字通过轮询 `/chatreply` 显示。

## 前置条件

1. 电脑端启动主程序 `api.py`（1800）。
2. 电脑端启动 GPT-SoVits（`.Sovits`，9880）——否则 AI 不会说话（声音在电脑端播放）。
3. 若要用「按住说话」语音识别，还需：
   - `config.yml` 中 `sensevoice.enabled: true`（默认已开启）
   - 启动 `.SenseVoice` 服务端（配置 GUI 有「启动 SenseVoice」按钮）

> 说明：AI 回复的**声音在电脑端播放**（mpv 本地播放），手机端只显示文字和接收语音输入；这是现有项目架构决定的，本文件夹未改动原项目。

## 启动

在项目根目录 `D:\.Meowlisis` 下：

```bat
runtime\python.exe .phone\serve.py
```

首次启动会自动生成自签名证书到 `.phone/cert/`。

## 手机访问

1. 手机与电脑连**同一局域网**。
2. 查看电脑局域网 IP（cmd 执行 `ipconfig`），例如 `192.168.1.5`。
3. 手机浏览器打开：

```
https://192.168.1.5:8443
```

4. 首次访问会提示「连接不是私密连接」，点 **高级 → 继续前往**（Android）或 **显示详细信息 → 访问此网站**（iOS）。
5. 点「按住说话」并允许麦克风权限，说话时按住、松开发送。

## 使用

- **按住说话**：按住按钮录音，松开发送，语音送 SenseVoice 识别后进入 LLM。
- **打字发送**：输入框打字回车或点「发送」。
- 桌宠画面显示在上方，对话文字显示在下方。

## 常见问题

- **麦克风无法授权**：必须用 `https://` 访问（http 会被浏览器拒绝 getUserMedia）。自签名证书要点「继续前往」后才可用麦克风。
- **语音发送了但 AI 没反应**：确认 SenseVoice 服务端已启动、主程序 `api.py` 已启动；或改用文字输入验证链路。
- **声纹过滤**：SenseVoice 识别结果会走 `target_speakers` + `speaker_threshold` 校验，若被过滤可调整 `config.yml`（原项目配置，本文件夹不代改）。
- **手机听不到 AI 声音**：正常现象，声音在电脑端播放。
- **端口被占用**：修改 `serve.py` 顶部 `PORT` 即可（默认 8443）。

## 目录结构

```
.phone/
├── serve.py          # HTTPS 服务 + 反向代理 + 证书生成
├── static/
│   ├── index.html    # 手机界面
│   ├── style.css     # 样式
│   └── app.js        # 录音上传 / 文字对话 / 轮询回复
└── cert/             # 自签名证书（首次启动自动生成）
```
